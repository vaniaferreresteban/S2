## 🛠️ Technologies Used

* HTML5 
* CSS3 
* JavaScript (ES6+) 

## ⚙️ Prerequisites

You need a web browser (Chrome, Firefox, Safari, etc.) to open and view the `index.html` file. No specific server or additional software is required for this basic exercise.

## 💾 Installation

No specific installation steps are needed for this exercise. To work with the files locally, you can clone the repository:

1.  Clone the repository:
    ```bash
    git clone 'https://github.com/vaniaferreresteban/S2.git'
    cd S2
    ```

## ▶️ Execution

1.  Open the `index.html` file in your web browser. You can do this by double-clicking the file or by right-clicking and selecting "Open with..." followed by your browser.


## 🚀 Deployment

This is a client-side exercise, so deployment in a traditional sense isn't strictly necessary. However, if you wanted to host this simple web page, you could upload the `index.html`, the `css` folder, and the `js` folder to a static file hosting service like GitHub Pages, Netlify, or Vercel.
